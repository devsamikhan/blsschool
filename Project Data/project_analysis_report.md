# Project Analysis Report: Blended Learning School (BLS)

## Overview
Aapka project ek **School Management System** hai jisay modern web technologies use kar ke banaya gaya hai. Ye system different users (Admin, Teacher, Student, Principal, Accountant) ke liye specific portals provide karta hai.

---

## Technical Stack (Tech Specs)
Project mein niche di gayi technologies use ho rahi hain:

*   **Frontend Framework**: React 18 (TypeScript ke sath).
*   **Build Tool**: Vite (Fast development speed ke liye).
*   **Styling**: Tailwind CSS aur Shadcn UI (Professional aur clean design ke liye).
*   **Animations**: Framer Motion aur Smooth Scrolling ke liye Lenis use kiya gaya hai.
*   **Data Fetching**: TanStack Query (React Query) API calls handle karne ke liye.
*   **Routing**: React Router Dom v6.
*   **Form Management**: React Hook Form aur Zod (Validation ke liye).
*   **Backend (Development)**: JSON Server use ho raha hai jo `db.json` file ko as a database treatment karta hai.

## Core Features & Modules

### 1. Unified Authentication System
*   Ek main Login page hai `/login`.
*   System identify karta hai ke user Admin hai, Teacher hai, ya Student, aur usay relevant dashboard par redirect karta hai.
*   `RequireAuth` component use kiya gaya hai routes ko protect karne ke liye.

### 2. Admin Dashboard (`/admin`)
*   **User Management**: Naye users add karna, delete karna aur roles assign karna.
*   **Class Management**: Classes aur sections create karna.
*   **Teacher Assignment**: Kis teacher ko kaunsi class aur subject dena hai.
*   **Logs & Settings**: System ki settings aur activity logs check karna.

### 3. Teacher Portal (`/teacher`)
*   **Attendance**: Students ki rozana ki hazri mark karna.
*   **Homework Management**: Homework create karna, list check karna aur students ki submissions ko marks dena.
*   **Announcements**: Class ke liye alerts ya notices jari karna.

### 4. Student Portal (`/student`)
*   **My Homework**: Apna homework dekhna, file/text submit karna aur check hua homework result dekhna.
*   **Fee Status**: Apni paid aur pending fees ka record dekhna.
*   **Announcements**: School ki taraf se di gayi updates check karna.

### 5. Principal Portal (`/principal`)
*   High-level view: School ke tamam students, teachers aur classes ki reports dekhna.
*   Announcements pure school ke liye publish karna.

### 6. Accountant Portal (`/accountant`)
*   **Fee Management**: Fees collect karna aur record update karna.
*   **Expenses**: School ke kharchay (e.g. Electricity, Salaries) record karna.
*   **Financial Reports**: Profit/Loss aur fee collection ki reports generate karna.

### 7. Public Website
*   **Home, About, Contact**: School ki general information.
*   **Admissions**: Online admission information.
*   **Academics**: Syllabus aur study programs ki detail.
*   **Gallery**: School events ki pictures ka display.

## Data Management
Aapka data `db.json` mein store ho raha hai. Niche data ki structure ki brief summary hai:
*   `users`: Sab roles ki details aur passwords.
*   `classes`: Available classes (Nursery to 8th etc).
*   `homework`: Teachers ka assign kiya hua kaam.
*   `submissions`: Students ka jama karwaya hua kaam.
*   `feeRecords`: Students ki fees ka hisab.
*   `expenses`: School ke financial kharchay.
