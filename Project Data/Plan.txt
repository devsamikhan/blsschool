# Complete Prompt for AI to Build the Blended Learning School (BLS) Management System

---

## Prompt:

Build me a complete, production-ready School Management System called **"Blended Learning School (BLS)"** from scratch using the following tech stack and specifications. Implement every single feature described below with full functionality, proper UI/UX, and clean code architecture. Do not skip any feature. Do not use placeholder or dummy data where real logic is needed. Every button, every form, every page must be fully functional.

---

## Tech Stack

- **Frontend:** React 18 + TypeScript + Vite
- **UI Library:** shadcn/ui + Tailwind CSS
- **State Management:** React Context API for authentication + local component state
- **Backend (Development):** JSON Server running on port 3001
- **Real-time Updates:** Custom window event system for cross-component communication
- **Routing:** React Router v6 with protected routes
- **Storage:** JSON Server as database (db.json file), localStorage only for auth persistence

## Authentication System (src/contexts/AuthContext.tsx)

Build a complete authentication context with:

1. **Login function** that takes schoolId and password, calls the API to find matching user, and stores user in state + localStorage
2. **Logout function** that clears state and localStorage
3. **getCurrentUser** that returns the logged-in user object
4. **isAuthenticated** boolean
5. **Persist auth** across page refreshes using localStorage
6. **Auto-redirect** based on role after login:
   - admin → /admin/dashboard
   - teacher → /teacher/dashboard
   - student → /student/dashboard
   - principal → /principal/dashboard
   - accountant → /accountant/dashboard

---

## Protected Route Component

Create `RequireAuth.tsx` that:
1. Checks if user is logged in
2. Checks if user has the required role
3. If not logged in → redirect to /login
4. If wrong role → redirect to their correct dashboard
5. If authorized → render children

## School ID Auto-Generation Logic

```typescript
function generateSchoolId(role: UserRole, existingUsers: User[]): string {
  const prefixMap = {
    admin: 'ADMIN',
    teacher: 'TCH',
    student: 'STU',
    principal: 'PRIN',
    accountant: 'ACC'
  };
  
  const prefix = prefixMap[role];
  const usersOfRole = existingUsers.filter(u => u.role === role);
  const nextNumber = usersOfRole.length + 1;
  return `${prefix}${String(nextNumber).padStart(3, '0')}`;
}
```
