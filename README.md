# BLS School Learning Management System (LMS)

A comprehensive, automated Learning Management System featuring an intelligent admission record engine and AI-driven data processing.

## Project info

**Repository URL**: https://github.com/devsamikhan/blsschool/

## How can I run or edit this code locally?

My development workflow is entirely Command-Line (CLI) driven. If you want to work locally using your own terminal and IDE, follow these steps.

The only requirement is having Node.js & npm installed.

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone [https://github.com/devsamikhan/blsschool.git](https://github.com/devsamikhan/blsschool.git)

# Step 2: Navigate to the project directory.
cd blsschool

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server.
npm run dev
